# Engineering Proxy Characterization Receipt Boundary

This receipt note exists to prevent the characterization result from being mistaken for biological calibration.

A future biological calibration must be introduced through a separate reviewed evidence gate with its own source provenance and cannot inherit authorization from this engineering characterization.
