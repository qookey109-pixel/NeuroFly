## Motivation

Cross-subsystem localization identified `v/g + refractory/delay` as the only
tested minimal pair that suppressed changed-KC activity, changed-edge
engagement and MBON07 state expression in all four neural-diverse histories.

This study asks whether that pattern replicates in a fresh outcome-blind
neural-diverse cohort.

## Replication criterion

The primary descriptive replication pattern is:

For each selected neural history, `clear_vg_delay` is lower than `intact`
on all three primary neural-expression endpoints:

- changed-KC active fraction
- changed-edge L1 engagement
- MBON07 state-difference fraction

There is no significance threshold and no promotion criterion.

The broad clear remains a mechanistic reference because previous runs showed
non-monotonic intervention effects.

## Interpretation boundary

A successful replication would strengthen the statement that
`v/g + refractory/delay` is a robust suppressive ensemble candidate.

It would still **not** identify a unique transient carrier, prove behavioral
memory causality, or justify promotion.
