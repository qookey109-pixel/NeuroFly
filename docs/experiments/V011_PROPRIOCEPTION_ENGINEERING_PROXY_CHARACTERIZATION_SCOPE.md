# Scope Boundary

Allowed in this stage:
- deterministic software characterization of existing engineering receptor channels;
- CI regression checks;
- human-readable diagnostic summaries.

Not allowed in this stage:
- changing the receptor channel set;
- exposing joint position or other private body state to the neural payload;
- systematic-type binding;
- biological current or conductance calibration;
- stimulation;
- predictive inhibition or phase gating;
- promotion of the unresolved polarity inference.
