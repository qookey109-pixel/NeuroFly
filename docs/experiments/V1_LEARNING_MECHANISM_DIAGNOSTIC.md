# V1 Learning Mechanism Diagnostic

## Why this stage exists

The seed-effectiveness remediation completed successfully, but the exploratory
learning signal remained negative. The next question is therefore mechanistic:
is the behavior caused by reinforcement timing, unreinforced plastic drift,
checkpoint persistence, decoder collapse, or some combination?

This stage does not tune learning parameters and does not authorize a learning
claim.

## Temporal-credit question

In the current GoalMazeSession sequence, action outcome is generated after the
brain has already decided.

That outcome is converted into a pending reinforcement signal and delivered on
the next brain decision.

Therefore the diagnostic records, for every decision:

1. previous outcome reward/event/action;
2. scheduled reinforcement;
3. actually delivered reinforcement;
4. digest of the sensory frame receiving that reinforcement;
5. decoder left/right rate, difference and gate spikes;
6. reward/aversive/KC spikes;
7. memory SHA and efficacy before and after the decision;
8. the new outcome generated by the action.

This records the temporal relation without changing it.

## Three-arm diagnostic

Each of three fresh matched replicates runs:

- `learning_true`: normal sensory input, learning enabled, real reinforcement;
- `learning_none`: normal sensory input, learning enabled, external
  reinforcement suppressed;
- `frozen_true`: normal sensory input, learning disabled, real reinforcement.

This isolates three questions:

- Does plasticity drift when external reinforcement is absent?
- Does true reinforcement add a distinct effect beyond that drift?
- Does frozen memory remain bitwise stable while receiving the same outcome
  signals?

## Persistence proof

Each arm is saved after training and immediately restored into a fresh
MaleCNSBrain instance.

The diagnostic requires the pre-save and post-restore memory records to match
exactly. A persistence failure invalidates execution rather than being
interpreted as a learning result.

## Claim boundary

All interpretation remains exploratory. In particular:

- `learning_validated = false`
- `temporal_credit_defect_confirmed = false`
- `unreinforced_plastic_drift_causal = false`
- `causal_learning_claim_authorized = false`
- `replacement_confirmatory_authorized = false`
- `behavioral_promotion_authorized = false`

A later change to timing, DAN baseline, eta, pulse parameters or decoder policy
would require a new explicitly versioned exploratory intervention rather than a
silent modification of this diagnostic.
