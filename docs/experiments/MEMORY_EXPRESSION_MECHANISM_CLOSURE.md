# Memory-Expression Mechanism — Closure

Status: **CURRENT LINE CLOSED**

This document closes the present NeuroFly reward-memory expression mechanism
localization sequence. It is an evidence boundary, not a claim of biological
completion.

## What the sequence established

1. **Persistent paired KC→MBON07 synaptic memory exists** after the frozen
   reward/no-pulse pairing protocol.

2. A state-cleared instantaneous reward cue is not a reliable expression
   trigger for that stored difference.

3. Longer exact temporal context improves downstream expression, but exact
   early prefix ordering is not necessary.

4. Scheduler representation was repeatedly endpoint-equivalent to intact and
   was excluded as the tested positive expression carrier.

5. Broad physical transient state strongly modulates stored-memory expression.

6. Cross-subsystem localization identified `v/g + refractory/delay` as a
   strong suppressive ensemble candidate, but fresh replication showed that
   the sign of its effect is **history dependent**.

7. Exploratory moderator discovery found boundary adaptation engagement as the
   strongest pre-intervention predictor of suppression versus non-suppression.

8. Fresh stratified validation reproduced that prediction:

   - adaptation-engaged: **4/4 suppression**
   - adaptation-quiescent: **0/4 suppression**, including 3 reversals
   - both preregistered directional targets passed.

## Current best mechanistic statement

**Stored KC→MBON07 memory expression in the current NeuroFly/MaleCNS assay is
strongly gated by transient neural state. Boundary adaptation engagement is a
replicated predictor of whether clearing v/g plus refractory/delay state
suppresses or instead releases/increases expression.**

The current evidence does **not** causally separate adaptation from the
perfectly correlated immediate-prefix expression state observed at lag -21.

## Explicitly excluded / unsupported claims

No result in this sequence should be presented as biological completeness,
behavioral-memory proof, consciousness, or a validated general learning
mechanism.

## Why this line stops here

Continuing to split fields without first resolving the adaptation/prefix-state
confound would add complexity without a clean increase in evidential strength.

The current line has reached a useful stopping point:

- persistent memory: demonstrated in the assay;
- expression dependency: demonstrated;
- scheduler bookkeeping: excluded;
- distributed physical-state dependency: localized;
- history dependence: replicated;
- adaptation-state predictor: independently replicated;
- causal identity: deliberately unresolved.

## Reopen rule

Reopen this research line only for a separately authorized,
preregistered **causal-disambiguation** experiment that directly distinguishes:

1. adaptation state, and
2. correlated immediate-prefix changed-KC / changed-edge expression.

Until then, this line is considered **closed and stable**.
